# Camera Shutter Sound

This directory should contain `camera_shutter.mp3` - a camera shutter sound effect.

## Getting a Shutter Sound

You can download a free camera shutter sound from:

1. **Freesound.org** - Search for "camera shutter" (requires free account)
   - https://freesound.org/search/?q=camera+shutter

2. **Zapsplat** - Free sound effects (requires free account)
   - https://www.zapsplat.com/sound-effect-categories/camera-sounds/

3. **Orange Free Sounds** - Free camera sounds
   - https://orangefreesounds.com/camera-shutter-sound/

4. **FreeSoundsLibrary** - Camera sound effects
   - https://www.freesoundslibrary.com/camera-shutter-sound-effect/

## File Requirements

- **Format**: MP3
- **Filename**: `camera_shutter.mp3`
- **Duration**: 0.1-0.3 seconds recommended
- **Quality**: 44.1kHz sample rate or higher

Place the downloaded file in this directory as `camera_shutter.mp3`.
